# Laby Sem 1

My repo for programming tasks from 1st semester of Algorithmic Computer Science @ WUST.

## Subjects

```
laby-sem1/
├── README.md
└── Wstęp do Informatyki i Programowania/    # Introduction to Computer Science and Programming
    ├── ADA-playground/                      # Ada experiments (tic-tac-toe)
    └── Labolatoria/                         # Lab lists, every task solved in Ada, C and Python
        ├── Lista 1/ ... Lista 6/
        └── Lista Dodatkowa/                 # Extra list
```

## Conventions

Every task is solved three times, in the directories suffixed with the language:

| Suffix | Language | Toolchain          |
| ------ | -------- | ------------------ |
| `a`    | Ada      | `gnatmake` / `gprbuild` |
| `c`    | C        | `gcc` / `cmake`    |
| `p`    | Python   | `python3`          |

Build artifacts and compiled executables are git-ignored.
