# Lista 3

## Tasks

| Task    | Description                                   |
| ------- | --------------------------------------------- |
| `zad_1` | Count primes up to `n` (sieve of Eratosthenes) |
| `zad_2` | Binomial coefficient                          |
| `zad_3` | `n`-th prime number                           |

Each task directory contains `zad_Na.adb`, `zad_Nc.c` and `zad_Np.py`.

## Building and running

Run the commands from inside a task directory, e.g. `zad_1`.

### Ada

```
gnatmake zad_1a.adb
./zad_1a
```

### C

```
gcc zad_1c.c -o zad_1c -lm
./zad_1c
```

### Python

```
python3 zad_1p.py
```
