# Lista 1

## Tasks

| Task    | Description                                       |
| ------- | ------------------------------------------------- |
| `zad_1` | Greatest common divisor (Euclid's algorithm)      |
| `zad_2` | Real solutions of a quadratic equation            |
| `zad_3` | Check whether a number is a palindrome in base `p` |

Each task directory contains `zad_NA.adb`, `zad_NC.c` and `zad_NP.py`.

## Building and running

Run the commands from inside a task directory, e.g. `zad_1`.

### Ada

```
gnatmake zad_1A.adb
./zad_1A
```

### C

```
gcc zad_1C.c -o zad_1C -lm
./zad_1C
```

### Python

```
python3 zad_1P.py
```
