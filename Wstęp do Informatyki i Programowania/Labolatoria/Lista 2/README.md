# Lista 2

## Tasks

| Task    | Description                                  |
| ------- | -------------------------------------------- |
| `zad_1` | Greatest common divisor as a function        |
| `zad_2` | Primality test                               |
| `zad_3` | Prime factorization (e.g. `360 = 2^3*3^2*5`) |

Each task directory contains `zad_Na.adb`, `zad_Nc.c` and `zad_Np.py`.

## Building and running

Run the commands from inside a task directory, e.g. `zad_1`.

### Ada

```
gnatmake zad_1a.adb
./zad_1a
```

### C

```
gcc zad_1c.c -o zad_1c -lm
./zad_1c
```

### Python

```
python3 zad_1p.py
```
